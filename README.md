# Brain Tumor Classification using Deep Learning

## Overview

This project presents a Brain Tumor Classification System developed using MobileNetV2 and Streamlit.

The system classifies brain MRI images into four categories:

* Glioma
* Meningioma
* Pituitary Tumor
* No Tumor

To improve interpretability, Grad-CAM and LIME explanations are provided to visualize the regions influencing the model's prediction.

## Features

* MRI Image Upload
* Brain Tumor Classification
* Confidence Score Display
* Grad-CAM Visualization
* LIME Explanation
* User-Friendly Streamlit Interface

## Technologies Used

* Python
* TensorFlow / Keras
* MobileNetV2
* Streamlit
* OpenCV
* LIME
* Matplotlib
* Scikit-Learn

## Running the Project

Install dependencies:

pip install -r requirements.txt

Run:

streamlit run app.py
